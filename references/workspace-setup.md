# 工作区配置与输入约定

本技能不绑定申请人的姓名、单位、毕业时间、成果、联系方式或本地目录。每次任务从用户提供的最新材料建立事实底稿，用户的明确更新优先。

## 输入

| 输入 | 用途 |
|---|---|
| 最新 CV PDF | 核对身份、教育、成果状态、项目职责和联系方式 |
| CV 可编辑原件（如 PPTX 或 DOCX） | 在副本中局部定制，保护冻结区域 |
| 导师姓名与官方主页 | 核查当前单位、近期研究、申请渠道和要求 |
| RS 参考稿（可选） | 继承用户认可的结构和版式 |
| 输出目录与申请范围 | 确定文件夹、原始编号及需要处理的导师 |

没有可编辑 CV 原件时，说明可用输入的限制，不把复制后的 PDF 冒称为已定制 CV。用户只要求其中一种材料时，只执行授权范围。

## 示例目录

以下仅是可调整的相对路径，不要求用户创建同名目录。

```text
application-workspace/
  inputs/                 # 用户提供的私人材料，不提交到技能仓库
  references/             # 用户指定的版式参考稿
  build/                  # 事实底稿、证据、工作副本、渲染和检查记录
  output/
    01_Advisor_Name/
      CV.pdf
      Research_Statement.docx
      Research_Statement.pdf
      套磁信.docx
```

## 继续已有批次

先读取本轮指定的文件、编号映射和输出目录，记录输入哈希。保留删除项形成的编号间隔，不重排既有目录。旧证据只作检索线索，不能证明岗位仍然开放、导师仍在同一机构或某篇论文仍处于原状态。

日期、论文状态、任职、成果数量和联系方式每轮重新核对。旧批次的附件列表、导师数量、国家筛选、对象 ID 和工具缓存路径不自动迁移。

## 个人配置与公开版本

如需保存个人约定，将其放在独立的私人工作区，并在当前对话中指定。不要把真实 CV、推荐人、申请记录、邮件、证据文件或本地绝对路径加入公开技能仓库。使用随附模板时必须替换所有占位符和 example.org 链接，再进行最终检查。
